                    Live Device Push
                    SSH · Dry-run by default
                

                

                    

                        Push generated Cisco IOS configurations to routers and switches over SSH.
                        Default mode is dry-run (prepares and probes only).
                        Use host 127.0.0.1 or lab.local for safe simulation without SSH.
                    

                    

                        
SSH authentication options

                        
    
                            
  • Password — fill Username + Password (and Enable secret if needed).
    • 
                            
  • SSH private key (file) — set Key path to a key file on the NETRIX server (e.g. /home/netops/.ssh/id_ed25519). Optional passphrase in Key pass.
    • 
                            
  • SSH private key (PEM paste) — expand Advanced and paste a PEM private key. Preferred in demos when the key is not on the server disk.
    • 
                            
  • Priority — if a key path or PEM is provided, key auth is used; password may still be sent if both are set.
    • 
                        

                        
Supported key types: Ed25519, ECDSA, RSA, DSA. OpenSSH and PEM formats via Paramiko.

                        
ssh-keygen -t ed25519 -f ~/.ssh/netrix_lab -C "netrix-lab"

                        
Copy the public key to the device: ip ssh pubkey-chain / username … key-string (IOS) or standard authorized_keys on Linux-based NOS.

                    

                    

                        
                        Live apply can disrupt networks. Confirm change control, credentials, and rollback before disabling dry-run.
